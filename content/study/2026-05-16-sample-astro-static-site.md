이 글은 샘플 콘텐츠입니다. 실제 운영 전에 삭제하거나 자신의 공부 기록으로 바꾸면 됩니다.

## 공부한 주제

Astro는 콘텐츠 중심 정적 사이트를 만들기에 적합한 프레임워크다. 빌드 결과는 HTML, CSS, JavaScript 파일로 만들어진다.

## 핵심 개념

- `src/pages`: URL이 되는 페이지를 둔다.
- `content`: Markdown 글을 보관한다.
- `public`: 이미지처럼 그대로 배포할 파일을 둔다.

## 다시 볼 포인트

GitHub Pages에 배포할 때는 `site` 주소와 Actions 설정을 함께 확인해야 한다.
