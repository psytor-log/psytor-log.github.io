라이브러리를 불러온다.
import pandas as pd
​
pd.read_csv( ) 로 csv 파일을 불러올 수 있다.
csv 파일을 titanic 변수에 넣어준다.
​
titanic을 입력하면 표의 위쪽 5개 row와 마지막 5개 row를 보여준다.
​

​
titanic 데이터 column 에 'Name'이 보이죠?

![pandas 기초 #12. 텍스트를 나누고, 붙이기](/images/uploads/naver-223329317518-02.png)

​
이름을 모두 소문자로 변환하는 코드다.
.str.lower() 를 하면 대문자를 모두 소문자로 변환 완료.

![pandas 기초 #12. 텍스트를 나누고, 붙이기](/images/uploads/naver-223329317518-03.png)

이제 성과 이름을 분리해 보자.
​

![pandas 기초 #12. 텍스트를 나누고, 붙이기](/images/uploads/naver-223329317518-04.png)

영어 이름은 성과 이름 사이를,로 구분하기도 한다.
Smith, John = John Smith 씨가 된다.
last name = Smith
first name = John
​
titanic["Name"].str.split(",") 을 해주면
titanic 변수에 있는 'Name' 열에 있는 문자에서 ,(콤마)를 기준으로 나눠주라는 의미다.

![pandas 기초 #12. 텍스트를 나누고, 붙이기](/images/uploads/naver-223329317518-05.png)

.split(",")을 했을 때와 하지 않았을 때 간격을 비교해 보면 확실히 알 수 있다.
​

last name 과 first name을 나눠서 기록하기를 해보자.

![pandas 기초 #12. 텍스트를 나누고, 붙이기](/images/uploads/naver-223329317518-06.png)

,(콤마)를 기준으로 나눈 문자 중 앞쪽은 last name이 되고
뒤쪽은 first name가 된다.
​
.get( ) 을 사용해서
앞쪽을 .get(0)으로 가져오고,
뒤쪽을 .get(1)로 가져올 수 있다.
​
python에서 첫 번째는 0 번째부터 시작하기 때문에
앞쪽을 get(0), 뒤쪽을 get(1) 번째로 불러온다.

![pandas 기초 #12. 텍스트를 나누고, 붙이기](/images/uploads/naver-223329317518-07.png)

이렇게 titanic[["firstname", "lastname"]]으로 묶어서 불러오며
구분된 이름이 있는 테이블을 얻을 수 있다.
