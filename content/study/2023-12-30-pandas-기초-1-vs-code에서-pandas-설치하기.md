pip install pandas를 입력하면 pandas 라이브러리가 설치된다.
​

![pandas 기초 #1. vs code에서 pandas 설치하기](/images/uploads/naver-223307376935-02.png)

pip list로 설치된 라이브러리 목록을 확인할 수 있다.
설치 전에 없던 pandas가 설치 후에 list에서 확인할 수 있다.

![pandas 기초 #1. vs code에서 pandas 설치하기](/images/uploads/naver-223307376935-03.png)

![pandas 기초 #1. vs code에서 pandas 설치하기](/images/uploads/naver-223307376935-04.png)

라이브러리를 불러올 때는 'import 라이브러리'이름을 사용한다.
import pandas as pd 를 입력하면 pandas를 사용할 수 있게 된다.
​
as pd 는 관행처럼 사용되는 것으로 pandas 를 전부 작성하는 대신 pd라는 축약어로 사용하겠다는 의미다.
​
pandas는 column(열)과 row(행)으로 이뤄진 데이터를 다룰 때 사용한다.
​
column과 row가 많이 헷갈린다. 가로, 세로 = 행, 열로 외워보자.
가로는 행(row), 세로는 열(column)
