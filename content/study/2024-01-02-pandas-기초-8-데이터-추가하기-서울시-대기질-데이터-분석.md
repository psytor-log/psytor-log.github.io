표를 다루다 보면 평균값을 추가해야 할 일들이 생긴다.
엑셀에서 늘 하던 익순한 작업을 python의 pandas라이브러리를 이용해서 해보자.
​
먼저 pandas를 불러온다.

![pandas 기초 #8. 데이터 추가하기(서울시 대기질 데이터 분석)](/images/uploads/naver-223309975023-02.png)

pandas 대신 pd라는 약어를 관용어처럼 사용한다.
​
실습을 할 엑셀 파일을 불러온다.
실습할 데이터는 23년 12월 한 달 간의 서울시 행정구역별 대기질 데이터를 준비했다.

첨부파일

 dust_Detail_Info .xls

 파일 다운로드

dust_Detail_info.xls 를 다운 받아 실습해도 좋고,
가지고 있는 엑셀 데이터를 사용해도 좋다.

![pandas 기초 #8. 데이터 추가하기(서울시 대기질 데이터 분석)](/images/uploads/naver-223309975023-03.png)

작업을 하는 폴더에 파일을 넣어주면 파일을 읽어올 때 편리하다.
​
pd.read_excel() 함수로 데이터를 읽어올 수 있다.
() 안에 './파일명.확장자'를 써준다.
​

![pandas 기초 #8. 데이터 추가하기(서울시 대기질 데이터 분석)](/images/uploads/naver-223309975023-04.png)

.head()로 데이터를 출력해 보니 상단에 불필요한 row가 있는 걸 확인했다.
불필요한 것을 지우고 데이터 부분만 불러오는 코드를 다시 작성해 보자.
row를 제외하는 코드는 skiprows = 제거하려는 row 수
​
몇 개 row를 제거해야 하는지 원본 데이터를 보자.
​

![pandas 기초 #8. 데이터 추가하기(서울시 대기질 데이터 분석)](/images/uploads/naver-223309975023-05.png)

1번과 2번 row가 빈 칸이다.
위 두 개 row를 제외하면 row 3번이 인덱스가 된다.
​

![pandas 기초 #8. 데이터 추가하기(서울시 대기질 데이터 분석)](/images/uploads/naver-223309975023-06.png)

row에는 행정구역
column에는 day가 들어갔다.
​
그럼 마지막 column을 하나 추가하고, 행정지역별 월 평균 대기질 데이터를 넣어보자.
​

![pandas 기초 #8. 데이터 추가하기(서울시 대기질 데이터 분석)](/images/uploads/naver-223309975023-07.png)

한 줄 코드를 살펴보자.
air_quality 변수에 ["Mean"]을 선택한다.
원본 데이터에 Meam 인덱스가 없었기 때문에 새로 만들게 된다.
​
그리고
.iloc를 이용해서 숫자 부분을 지정한다.
​
row는 전체를 선택하고,
column 1은 행정구역명이 들어 있기 때문에 제외해야 한다.
따라서 .iloc[ : , 1: ]를 사용한다.
​
그리고 이어서
.mean(axis=1)을 입력해서
평균값을 1줄씩 구하는 명령을 입력한다.
​
마지막으로 대기질 평균값을 sort해보자.

![pandas 기초 #8. 데이터 추가하기(서울시 대기질 데이터 분석)](/images/uploads/naver-223309975023-08.png)

sort_air_quality에 Mean값을 오름차순으로 정리하기 코드를 입력하면
23년 12월 한 달 동안 공기가 좋았던 동네는 어디였는지 알 수 있다.
​
