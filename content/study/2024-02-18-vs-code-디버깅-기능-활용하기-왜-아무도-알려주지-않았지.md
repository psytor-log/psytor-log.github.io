프로그래밍을 처음 배울 때 anaconda의 jupyter Notebook 으로 연습을 시작했다.

![VS Code 디버깅 기능 활용하기왜 아무도 알려주지 않았지?](/images/uploads/naver-223356885698-01.png)

JupyterNotebook의 장점은 코드를 구간별로 실행하면서 결과를 확인할 수 있다는 것인데
이런 기능은 프로그래밍 입문자인 나에게 편리한 기능이었다.
​
그러다가 점점 익숙해지면 VS Code를 사용하게 된다.
무료이면서 여러 기능을 제공하기 때문에 AI 공부를 할 때는 VS Code 를 사용했다.
​
배우는 동안 Pycharm을 사용하기도 하고, Spyder로 하는 경우도 보았지만
python은 대부분 VS Code를 사용하더라.
​
VS Code의 또 다른 장점으로 Debug 기능이 있는데 배우는 동안에 아무도 알려주는 사람이 없었다.
그리고 오늘에서야 VS Code 의 debug 기능을 어떻게 쓰는지 알게 됐다.
​
이거 좋은 기능인데, 왜 아무도 알려주는 사람이 없었을까?
의문이다.
​

![VS Code 디버깅 기능 활용하기왜 아무도 알려주지 않았지?](/images/uploads/naver-223356885698-02.png)

디버그 기능은 .ipynb (Jupyter Notebook) 환경에서는 작동하지 않았다.
.py 로 작업할 때 작동하는 기능이다.
​

디버그 기능 시작하기.
​

![VS Code 디버깅 기능 활용하기왜 아무도 알려주지 않았지?](/images/uploads/naver-223356885698-03.png)

삼각형 플레이 버튼과 벌레 모양이 함께 있는 아이콘을 누르면 위 화면과 같이 뜬다.
그럼 create a launch.json file을 클릭하자.

![VS Code 디버깅 기능 활용하기왜 아무도 알려주지 않았지?](/images/uploads/naver-223356885698-04.png)

Python Debugger 클릭하면

![VS Code 디버깅 기능 활용하기왜 아무도 알려주지 않았지?](/images/uploads/naver-223356885698-05.png)

선택 화면이 바뀐다.
Python File을 선택해 보자.
​

![VS Code 디버깅 기능 활용하기왜 아무도 알려주지 않았지?](/images/uploads/naver-223356885698-06.png)

그럼 좌측 화면이 3단으로 구성된 화면으로 변경되고, laungh.json 탭이 생긴다.
탭은 닫기를 눌러도 된다. 이미 작업 폴더에 json 파일이 생성되어 있다.

![VS Code 디버깅 기능 활용하기왜 아무도 알려주지 않았지?](/images/uploads/naver-223356885698-07.png)

그럼 여기까지 디버그를 할 수 있는 환경 세팅이 완료된 것이다.
​

디버그 해보기.
​

![VS Code 디버깅 기능 활용하기왜 아무도 알려주지 않았지?](/images/uploads/naver-223356885698-08.png)

코드 라인 숫자 좌측에 마우스를 가져가면 빨간점이 생긴다.
클릭을 하면 빨간점이 진하게 변하면서 찍히는데 빨간점이 표시된 코드까지 실행을 한다는 의미다.
​
빨간점을 찍고 디버그 창에 녹생 실행 버튼을 클릭하자.

![VS Code 디버깅 기능 활용하기왜 아무도 알려주지 않았지?](/images/uploads/naver-223356885698-09.png)

녹색 실행 버튼을 클릭하면 화면의 변화가 많이 나타난다.
​

![VS Code 디버깅 기능 활용하기왜 아무도 알려주지 않았지?](/images/uploads/naver-223356885698-10.png)

먼저 새로운 메뉴가 나타난다.

![VS Code 디버깅 기능 활용하기왜 아무도 알려주지 않았지?](/images/uploads/naver-223356885698-11.png)

새로 생긴 아이콘 박스다.
두 번째 아이콘을 누르면 한 줄씩 실행을 해나간다.
​
아이콘의 기능이 직관적이긴 한데, 눌러보면 더 확실히 알 수 있다.
​

![VS Code 디버깅 기능 활용하기왜 아무도 알려주지 않았지?](/images/uploads/naver-223356885698-12.png)

아래 터미널 창에는 해당 코드까지 실행된 결과가 나타나면서 코드의 오류가 있는지 확인할 수 있다.
​

![VS Code 디버깅 기능 활용하기왜 아무도 알려주지 않았지?](/images/uploads/naver-223356885698-13.png)

좌측에 Locals 에는 실행되는 코드 값들이 나오는데
더블 클릭해서 값을 수정해 볼 수 있다.
​
​
WATCH 창에는 + 버튼을 눌러서 변수를 등록할 수 있다.
그럼 코드에서 등록한 변수가 등장할 때 변수 값을 보여준다.
그럼 그 변수를 수정하고, 수정된 값으로 코드를 돌려보면서 버그를 해결할 수 있다.

![VS Code 디버깅 기능 활용하기왜 아무도 알려주지 않았지?](/images/uploads/naver-223356885698-14.png)

​
​

Debug 기능은 복잡하고 긴 코드에서 어느 부분에서 오류가 났는지를 확인하고
수정해 보면서 실행 결과를 체크해 볼 수 있는 기능이다.
​
활용하면 유용하게 사용할 수 있는데 왜 아무도 알려주지 않았는지...
​
