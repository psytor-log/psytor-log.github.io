파이썬으로 데이터 분석을 할 때 위치 정보를 활용하는 경우가 있다.
예를 들면 이런 식으로 지도 위에 스타벅스 매장 분포를 나타내는 지도를 그려보는 경우
파이썬으로 분석을 할 수 있다.

![파이썬 leafmap으로 지도 다루기 #1. 설치](/images/uploads/naver-223316835538-01.png)

파이썬으로
지도 사용이 가능한 Leafmap 설치를 어떻게 하는지 기초부터 시작해 보자.
​
vs code로 쥬피터 노트북 환경을 만들어서 실습을 해본다.
​

![파이썬 leafmap으로 지도 다루기 #1. 설치](/images/uploads/naver-223316835538-02.png)

연습을 위한 폴더를 하나 만든다.
프로그래밍 언어 코드를 실습을 하다 보면 파일이 뒤죽박죽 쌓여서
나중에 어떤 파일이 무슨 기능이었는지 모른다.
처음부터 폴더를 구분하고, 정리를 해두는 것이 좋다.
​

![파이썬 leafmap으로 지도 다루기 #1. 설치](/images/uploads/naver-223316835538-03.png)

설치 실습을 해볼 거니까
파일 추가 버튼을 눌러서
1_install.ipynb 파일을 만든다.
​

![파이썬 leafmap으로 지도 다루기 #1. 설치](/images/uploads/naver-223316835538-04.png)

쥬피터 노트북 환경에서 사용할 kernel 을 선택해 줘야 한다.
가상환경을 만들어서 하는 것이 정석이지만
연습이니까 그냥 base를 선택해서 진행하겠다.
​
pip install leafmap
으로 라이브러리 설치하기.
​

![파이썬 leafmap으로 지도 다루기 #1. 설치](/images/uploads/naver-223316835538-05.png)

pip list 로 설치되 라이브러리 목록 확인이 가능하다.
​

![파이썬 leafmap으로 지도 다루기 #1. 설치](/images/uploads/naver-223316835538-06.png)

사용할 라이브러리를 불러와 줘야 한다.
import leafmap으로 라이브러리 소환.
​
map = leafmap.Map()
map 변수에 leafmap에서 제공하는 지도를 넣는다.
​
map을 불러오면 지도가 나타난다.

![파이썬 leafmap으로 지도 다루기 #1. 설치](/images/uploads/naver-223316835538-07.png)

지도에서 우리나라를 바로 불러보자.
경도와 위도 값을 줘서 지도의 특정 위치를 볼 수 있다.
대한민국 :
위도 33~43도
경도 124~132도
​
서울은 37.5 / 126.9 정도 된다.
​
출력되는 지도의 중심을 위도, 경도 값으로 지정해 주고,
확대를 얼마나 할지 정해 줄 수 있다.

![파이썬 leafmap으로 지도 다루기 #1. 설치](/images/uploads/naver-223316835538-08.png)

서울의 위도와 경도 값을 넣고, 줌을 10배 정도 해보자.
​

![파이썬 leafmap으로 지도 다루기 #1. 설치](/images/uploads/naver-223316835538-09.png)

지도에서 서울을 찾았다.
​
지도도 바꿀 수 있다.

![파이썬 leafmap으로 지도 다루기 #1. 설치](/images/uploads/naver-223316835538-10.png)

import leafmap.foliumap as leafmap
을 하고
leafmap.Map 함수에 google_map = "HYBRID' 를 넣으면
위성사진 지도를 불러올 수 있다.

![파이썬 leafmap으로 지도 다루기 #1. 설치](/images/uploads/naver-223316835538-11.png)
