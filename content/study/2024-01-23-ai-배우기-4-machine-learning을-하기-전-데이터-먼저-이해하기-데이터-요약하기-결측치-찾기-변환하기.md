머신러닝을 하기 전,
우리는 데이터가 어떻게 생겼는지를 먼저 이해하는 과정이 필요하다.
​
인공지능에서 데이터는 조형물의 뼈대처럼 중요하다.
뼈대가 부실하면 조형물은 무너지는 것처럼 데이터가 부실하면 인공지능은 우리가 기대하던 역할을 해내지 못한다.
​
내 손에 들고 있는 데이터가 어떤 데이터인지 알아야
데이터 분석에 적합한 형태로 수정하거나 변형하는 것이 가능하기 때문에
데이터를 이해하고 수정할 수 있는 몇 가지 실습을 해보자.

​
​
불러온 데이터의 길이는 891이다.
그런데 데이터 정보를 보면 일부 column에서 891보다 부족한 데이터가 있다는 것을 확인할 수 있다.

결측치가 없으면 False로 결과를 보여준다고 생각하자.
​

.describe( ) 를 하면 수치 데이터에 대한 요약 정보를 확인할 수 있다.

![AI 배우기 #4 Machine Learning을 하기 전 데이터 먼저 이해하기. 데이터 요약하기, 결측치 찾기, 변환하기.](/images/uploads/naver-223330824723-07.png)

passengerID 의 count 값이 891이니까 전체 데이터의 수를 파악할 수 있다.
​
Survived 의 mean 값은 0.38 수준이다. 생존자가 1, 사망자가 0이니까 사망자가 훨씬 많다는 의미다.
​
Pclass는 min 값이 1, max 값이 3이다. 1등석~3등석까지 존재했다는 것을 알 수 있다.
​
Age의 mean 값은 약 29.7세다 그리고 std(표준 편차)가 약 14.53세니까 폭넓은 연령대가 탑승했다는 점도 알 수 있다. min 값은 0.42세인데 1세가 안된 영아가 탑승한 것 같다. (정확히 0.42가 어떤 나이인지는 모르겠다.)
​
SibSp와 Parch는 원본 데이터를 살펴볼 필요가 있다.

오타인지, 아웃라이어가 존재하는지 확인을 하면 더 좋은 분석도 가능할 것 같다.
Fare 값도 확인이 필요하다. max 값이 너무 크다.

​
이렇게 데이터를 보면서 하나씩 정리해 나가는 작업이 필요하다.
​

​
수가 아닌 다른 유형의 요약 자료 분석.
​

![AI 배우기 #4 Machine Learning을 하기 전 데이터 먼저 이해하기. 데이터 요약하기, 결측치 찾기, 변환하기.](/images/uploads/naver-223330824723-08.png)

column에 있는 object를 요약으로 확인 가능하다.
​
.describe(include='object')
를 입력하면 자료 유형이 'object'인 데이터에 대한 요약을 확인할 수 있다.
​
count : 빈도
unique : 종류 수
top : 데이터 중 다수 검출된 것의 빈도를 표기한다. 빈도가 같은 때는 가장 처음 데이터를 보여준다.
freq : top이 몇 개 인지
​

데이터 분석에 사용될 데이터를 이해하는 것은 중요한 작업이다.
획득한 데이터를 빠르게 이해하고, 분석에 최적화된 형태로 수정/보완하는 감각을 키우기 위해서는
위에 소개된 방식으로 데이터를 뜯어보는 시간을 충분히 가질 필요가 있겠다.
