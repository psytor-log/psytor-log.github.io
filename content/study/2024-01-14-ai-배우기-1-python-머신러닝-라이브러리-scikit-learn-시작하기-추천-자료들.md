​
사이킷-런 홈페이지에서 6가지 기능을 소개하고 있다.
​
분류 (Classification)
회귀 (Regression)
군집화 (Clustering)
차원 축소 (Dimensionality reduction)
모델 선택 ( Model selection)
전처리 (Preprocessing)
​
​
분류 (Classification) : 개체가 어떤 카테고리에 속하는 것인지 알아내는 것이다. 예들 들어서 스팸 메일을 알아서 걸러주는 기능을 구현할 때 사용된다.
​
회귀 (Regression) : 예측을 할 수 있다. 집값을 예측한다거나 병을 예측한다거나 하는 기능에 사용된다.
​
군집화 (Clustering) : 비슷한 것끼리 묶는 기능이다. 사용 고객을 세분화하여 카테고리화한다거나 유사한 타입을 구분하는 기능을 구현할 수 있다.
​
차원 축소 (Dimensionality reduction) : 변수를 줄인다. 사회과학에서 사용되기도 하는데 어떤 개념에 영향을 미치는 하위 요인이 여러 가지일 때 복잡한 요인을 축소하는 것이다.(설명이 좀 애매하군)
​
모델 선택 ( Model selection) : 모델을 비교하고, 검증해서 정확도를 높이는 용도다.
​
전처리 (Preprocessing) : 머신러닝에 사용될 데이터를 수정하거나 변환하는 작업을 의미한다.
