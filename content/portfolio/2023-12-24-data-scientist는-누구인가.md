앞으로 10년 동안 Data Science를 하기 위해
Data Scientist는 어떤 사람인지에 대해 나만의 정의를 가지고 있는 것이 좋을 것 같다.
​
데이터 사이언티스트라는 말이 생겨나기 이전에도
데이터를 다루는 사람들은 이미 존재했다.
​
시대가 변화하면서 Data의 양이 미친 듯이 늘어났고,
분석 툴, 프로그래밍, 시각화 스킬이 향상되면서
전문적으로 Data를 다루는 인력이 더 많이 필요해졌다.
​
점점 늘어나는 수요에 따라서 그들을 부를 새로운 이름이 필요했고,
Data Scientist라는 이름표가 생겼다.
​
데이터 사이언티스트의 정의는 모호한 면이 있다.
데이터 분석가, 데이터 엔지니어는 데이터 사이언티스트와 경계가 모호하다.
나름 그들 사이에서는 구분이 있는 것 같지만...
채용공고를 보면 그런 구분이 큰 의미가 없어 보인다.
​

데이터 사이언티스트
: 데이터를 과학적으로 다루는 사람.

데이터 사이언티스트가 누구야?라고 물으면
답하는 사람마다 다른 답을 한다.
​
Coursera 에서 Data Science 강의를 듣는데
IBM 개발자들, 전문가들이 위 질문에 답을 하는 장면이 나왔다.
전부 다른 답변을 내놓았다.
​
하지만 맥락은 모두 같다.
데이터 사이언티스트의 핵심이 무엇인지 한번 찾아가 보자.
​
가장 먼저 '과학자'에 대해서 생각해 봐야 한다.
과학자는 다음과 같은 것을 한다.
​
호기심을 갖고,
문제를 정의하며,
가설을 세우고,
근거를 가지고 가설을 검증하고,
문제의 답을 탐색한다.
​
호기심으로 시작해서 문제의 답을 탐색하는
과정을 전문적으로 해낼 수 있는 사람 이 과학자다.
​
이 정의에는 2가지 숨은 뜻이 있다.
​
하나. 과학자는 답을 찾는 방법론을 아는 사람이다.
"대충 직감으로~~~ "
"내 경험으로~~~"
처럼 말하면서 답을 찾지 않는다.
​
둘. 과학자는 '결론'전문가가 아닌 '과정'전문가다.
자신이 알고 있는 것만 연구하는 것은 과학자가 아니다.
미지의 영역, 아직 밝혀지지 않은 사실, 숨겨진 진실에 접근해 가는 사람이 과학자다.
과학자는 호기심을 잃어버리면 안 된다.
​
그래서,
데이터 사이언티스트는?
​
데이터에 호기심을 가지고,
문제를 정의하고,
가설을 세워서,
데이터로 근거를 찾고,
문제의 답(인사이트)에 접근해 가는 사람.
​
이런 사람이 되기 위한 전문적인 역량을 갖춘 사람이
Data Scientist다.
​
과학자는 자신의 분야에 대한 지식과 툴 사용 스킬을 가지고 있다.
Data Scientist의 전문 역량도
데이터에 대한 지식과 프로그래밍 스킬을 갖추는 것이다.
​
지금까지 푼 썰을 정리해 보면 다음과 같다.

데이터 사이언티스트 는
​
데이터에 호기심 을 가지고 문제의 정의부터 결론을 도출하는 과정 을 전문적으로 수행할 수 있는 사람이며,
이를 위해 데이터에 관한 깊은 지식 과 데이터 활용 툴 을 사용할 수 있는 사람이다.
