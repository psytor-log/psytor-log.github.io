이 글은 샘플 콘텐츠입니다. 실제 운영 전에 삭제하거나 자신의 프로젝트 기록으로 바꾸면 됩니다.

## 문제

개인 기록을 여러 서비스에 흩어 두면 장기적으로 이전과 백업이 어렵다.

## 목표

Markdown 글과 이미지 파일만으로 운영할 수 있는 개인 홈페이지 구조를 만든다.

## 접근 방식

Astro를 사용해 정적 사이트를 만들고 GitHub Pages로 배포한다. 새 글은 `inbox` 폴더에 넣은 초안을 스크립트로 변환한다.

## 결과

초기 메뉴, 샘플 콘텐츠, 글 변환 명령을 갖춘 실행 가능한 최소 버전을 만들었다.

## 배운 점

자동화는 완전한 CMS보다 단순한 규칙과 기록이 중요하다.
