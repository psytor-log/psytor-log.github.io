온라인 쇼핑, 엔터테인먼트, 마케팅, 제조, 금융, 의료 산업의 공통점은 무엇일까요?
모두 '데이터'를 사용하는 산업입니다.
​
데이터 분석 기술은 지금도 그렇지만
앞으로도 필요한 기술이라는 것에 이견은 없을 겁니다.
​
데이터의 중요성이 강조되는 덕분에
많은 온라인 강좌에서 '데이터 애널리틱스'과정을 공개하고 있습니다.
​
cousere에서 들을 수 있는
[Google 데이터 애널리틱스 수료증 과정]을 듣는 중 간편하면서도 활용이 쉬운 툴이 있어 정리해 봅니다.
​

![Google 프로그램 매니저가 알려주는 데이터 분석 스킬 체크리스트](/images/uploads/naver-223316084339-01.png)

데이터 분석을 잘하기 위해서 필요한 역량은 무엇일까?

데이터 분석을 잘하기 위해서 필요한 것은 어떤 역량일까요?
구글 프로그램 매니저가 알려주는 5가지 핵심은 다음과 같습니다.
​
호기심 : 적절한 질문을 통해 어떤 주제에 대해 더 많이 알고 싶어 하는 마음.
맥락을 이해 : '큰 그림'을 보고 정보고 어디쯤 있는지 이해하는 스킬.
기술적 사고방식 : 큰 목표를 작은 목표 단위로 쪼개는 능력.
데이터의 설계 : 데이터와 정보를 어떻게 구성해야 하는지 생각하는 역량.
데이터 전략 : 데이터 분석과 관련된 자원(사람, 프로세스, 툴, 프로그램 등)을 활용하는 능력
​
입니다.
​

데이터 분석의 5가지 핵심 역량을 갖추기 위해 가장 먼저 필요한 것은?

무엇보다 가장 먼저 해야 할 것은 현재 나의 수준을 파악하는 일이겠지요.
아래 표는 현재 나의 상태를 평가해 볼 수 있는 간단한 방식을 나타낸 것입니다.
​

![Google 프로그램 매니저가 알려주는 데이터 분석 스킬 체크리스트](/images/uploads/naver-223316084339-02.png)

강점, 개발 필요, 양성 필요 그리고 코멘트/계획/목표를 작성하면 되는데요.
강점~양성 필요 칸은 내 수준에 맞는 것을 골라 체크를 하고, 코멘트/계획/목표는 이후 따라오는 질문에 답을 하면서 작성하는 칸입니다.
​
강점~앙성 필요로 구성된 평가 단계를 설명해 볼게요.
​
강점은 그 부분에 풍부한 경험이나 지식이 있어서 스스로 강점이라고 생각할 만큼 자신감을 가지고 있는 영역입니다.
개발 필요 단계는 어느 정도 경험을 해봤지만 전문성을 갖기 위해서 노력이 필요하다는 의미고요.
앙성 필요 단계는 아직 경험하기 전이기 때문에 새로운 시작이 필요한 단계를 의미합니다.
​

![Google 프로그램 매니저가 알려주는 데이터 분석 스킬 체크리스트](/images/uploads/naver-223316084339-03.png)

이런 식으로 했다고 가정해 보겠습니다.
​
그리고 다음 질문에 답을 스스로 해봅니다.
​
질문 ) 각 영역에서 스스로 평가한 등급을 고려할 때, 가장 중요해 보이는 영역에서 자신을 어떻게 평가했나요?
질문 ) 일주일 후 이 영역의 경험 수준을 다시 평가해달라고 요청을 받는다면 어떻게 평가할 것이며, 그 이유는 무엇인가요?
질문 ) 앞으로 어떻게 스킬을 개발할 계획인가요?
​
이런 방식으로 항목을 정하고, 평가하고, 개선할 방법을 고민하고 기록해 보는 것이 데이터 분석가로 성장하는 방법입니다.
